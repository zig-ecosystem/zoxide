## 发现并修复的真机 bug

atomic_counter 初版死锁：LLVM 将 `bar.sync` 复制到 `if (tid==0)` 条件分支两侧（extern 声明缺 convergent/noduplicate 属性），与 cuda-oxide 禁用 JumpThreading 同类。修复：条件初始化改为全线程无条件写；编码规则记入 README 已知问题。修复版本 v0.3.1-alpha 复验 PASS。

## SGEMM swizzle（2026-09-20，v0.5.0 产物）

| kernel | n | GFLOPS | % 峰值 | 校验 |
|---|---|---|---|---|
| sgemm_swz（bank-conflict-free 列重映射） | 4096 | 18835.2 | **42.8%** | PASS |
| sgemm_swz 边界 | 4000 | 17548.9 | 39.9% | PASS |
| sgemm_swz 标量兜底路径 | 4095 | 14659.5 | 33.3% | PASS |

进展：34.8% → 42.8%（+8pp）。关键认识：冲突是行内的（16 tx 读同一 k 行 stride-8），行键 XOR swizzle 数学上无解，
修法是 fragment 列重映射（{4tx..4tx+3}∪{64+4tx..64+4tx+3}），存储布局不变、零额外指令。
SGEMM 优化线暂告段落：6.3% → 9.9% → 34.8% → 42.8%，每步瓶颈都有诊断证据。
